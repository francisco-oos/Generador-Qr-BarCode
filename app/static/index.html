Principio de seguridad

Marking Studio no sustituye LightBurn, Sculpfun Space ni LaserGRBL. Genera diseño, lotes, manifiestos y trazabilidad; el software de la máquina conserva movimiento, potencia y disparo.

Esto permite evolucionar plantillas y datos sin duplicar un controlador láser que ya funciona.
Flujo rápido: 1) elija plantilla → 2) escriba el ID → 3) revise la vista previa → 4) exporte SVG → 5) abra en LightBurn/Sculpfun Space → 6) aplique el ajuste del área, haga Frame y grabe → 7) escanee para verificar.

Biblioteca de materiales

Referencia de investigación para SCULPFUN S9 Pro / diodo azul 10 W. Los rangos publicados sirven sólo para iniciar pruebas; un ajuste ya validado por el área sobre la misma máquina, material y superficie tiene prioridad.

Superficies de teléfonos

La marca por sí sola no determina el material. Consulte el modelo exacto y use el ajuste local ya probado cuando exista. Si la composición no está confirmada, la alternativa segura es una placa/etiqueta apta para láser.

Jerarquía de ajustes

  1. Ajuste del área ya validado para la misma SCULPFUN, material/superficie y operación.
  2. Recomendación específica del fabricante, si existe y corresponde al mismo equipo.
  3. Rango de investigación como punto de partida.
  4. Material Test conservador y aprobación local antes de producción.
No se publica un “preset universal para plástico” ni un preset directo para un teléfono ensamblado de material desconocido.
